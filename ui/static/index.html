대기 중
탐지를 중지할까요? 지금까지 점검한 내용은 저장되지 않습니다.

이렇게 사용하세요

URL 하나만 넣으면 하위 페이지와 게시글, iframe까지 자동으로 점검합니다.

  1. 점검할 웹사이트의 시작 주소를 넣고 탐지 시작을 누릅니다.
  2. 불법광고가 탐지 유형(닮은꼴 글자, 자모 분해, 투명 텍스트, 화면 밖 은닉, 숨기지 않고 게시된 광고)별로 걸러집니다.
  3. 항목을 누르면 판정 근거를 확인하고 검토 상태와 메모를 남길 수 있습니다.
  4. 광고를 조치 완료로 처리할수록 청정도가 올라갑니다. 결과는 엑셀(CSV)로도 확인할 수 있습니다.
-
-

    청정도 산정 기준

    • 위 네 가지 지표를 함께 보고, 상태가 나쁜 지표를 더 크게 반영합니다.
    • 막대가 길수록 청정도를 많이 낮춘 지표입니다.
    • 광고를 조치 완료나 오탐으로 처리하면 청정도가 올라갑니다.
